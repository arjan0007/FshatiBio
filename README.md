# 🥛 FshatiBio - Platforma e Produkteve BIO të Fshatit

Platforma më e besueshme dhe më e thjeshtë në Shqipëri për të blerë produkte BIO të fshatit, me cilësi të garantuar dhe shpërndarje të shpejtë.

## 📋 Përshkrimi i Projektit

**FshatiBio** është një marketplace B2C ku brand-i unik blen produkte BIO direkt nga fermerët dhe i shpërndan te konsumatorët. Furnizuesit (fermerët) nuk shfaqen publikisht - konsumatori blen vetëm nga "FshatiBio".

### Produkte
- Qumësht, djathë, gjalpë, kos
- Vezë
- Mish pule/zogj fshati
- Mish viçi, mish qengji
- Produkte të tjera bulmeti

## 🏗️ Arkitektura e Projektit

Projekti përbëhet nga 4 komponentë kryesorë:

1. **Backend API** - Node.js/Express me PostgreSQL
2. **Mobile App** - Flutter (iOS & Android)
3. **Web Platform** - Next.js/React
4. **Admin Panel** - Next.js/React (dashboard për stafin)

## 🚀 Teknologjitë

### Backend
- Node.js / Express
- PostgreSQL
- JWT Authentication
- AWS S3 / Firebase Storage (për foto)
- Firebase Cloud Messaging (push notifications)

### Frontend
- **Mobile**: Flutter
- **Web**: Next.js / React
- **Admin**: Next.js / React

### Payment
- Paysera / Stripe
- Cash on Delivery (primare)

### Deployment
- AWS / DigitalOcean
- Load Balancer
- Auto Scaling
